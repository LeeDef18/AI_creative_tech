# Лабораторная 6 — вариант 23

Исследование влияния guidance_scale на визуал экологического лектория. В режиме A используется значение 0.0, в режиме B — 3.0. Остальные параметры совпадают.

[Задание](ЛР06_Исследование_параметров_text_to_image.pdf) · [Блокнот Colab](colab/LR06_23.ipynb) · [Гипотеза и допуски](reports/hypothesis.md) · [Скрипт](tools/run_lab06.py)

Эксперимент выполнен 15.10.2026 в Google Colab на Tesla T4. [Отчёт Word](reports/Король-Алексей-Юрьевич_ЛР1-6_вариант-23.docx) содержит таблицы, сравнительный лист, анализ изображений и ответы на контрольные вопросы. В блокноте сохранён вывод выполненных ячеек.

## Результаты

[Папка запуска](artifacts/v23_20261015_162954_090155/) · [Итоговая таблица](artifacts/v23_20261015_162954_090155/summary.csv) · [Сравнительный лист](artifacts/v23_20261015_162954_090155/comparison.png) · [Наблюдения](reports/observations.md) · [Проверка](reports/validation.log)

При guidance=3.0 среднее сходство CLIP снизилось на 2,0591 пункта. Энергия границ выросла на 88,06%, контраст — на 108,01%, время генерации — на 21,00%. Все изменения превысили 2s и исходные допуски. На изображениях появились резкие перепады, чрезмерно яркие зелёные участки и цветные артефакты. Для мягкого визуала леса выбран режим guidance=0.0.

При guidance=1.0 CFG остался выключен; изображение совпало с результатом при 0.0 по пикселям и SHA-256. При удвоении практических допусков оценка времени стала нейтральной, остальные классификации сохранились. Замедление близко к исходной границе 20%, поэтому его практическая оценка чувствительна к условиям измерения.

Контрольные суммы, таблицы и вывод блокнота проверены. Энергия границ и контраст независимо пересчитаны по 20 изображениям основной и демонстрационной серий. Повторная генерация и повторный расчёт CLIP локально не выполнялись. Команда проверки из папки лабораторной — `python3 tools/verify_results.py`; требуются Python 3.10+ и Pillow.

## Условия эксперимента

| Параметр | Значение |
|---|---|
| Бриф | Полог леса сверху, зелёные слои, мягкий утренний свет |
| Модель | stabilityai/sd-turbo |
| Ревизия модели | b261bac6fd2cf515557d5d0707481eafa0485ec2 |
| Оценка соответствия брифу | openai/clip-vit-base-patch32 |
| Ревизия CLIP | 3d74acf9a28c67741b2f4f2ea7635f0aaf6f0268 |
| Seed | 101, 102, 103, 104, 105 |
| Размер, шаги | 512×512, один шаг |
| Вычисления, генератор | float16 на GPU, свежий генератор на CPU |
| Изменяемый фактор | guidance_scale: 0.0 → 3.0 |

В обоих режимах используется английский запрос из `BRIEFS[3]`. Для каждой пары сохраняются изображения и четыре показателя: сходство CLIP с исходным брифом, энергия границ, контраст и время генерации. Оба режима предварительно прогреваются. Загрузка моделей и вычисление CLIP не входят во время генерации.

Итоговая таблица содержит среднее A, выборочное стандартное отклонение s в режиме A, среднее B, разность Δ и отношение |Δ|/s. Учебный критерий |Δ|>2s сравнивается с заранее выбранным практическим допуском. Допуски составляют ±1 для CLIP, ±10% для энергии границ и контраста, ±20% для времени. Рост визуальных метрик рассматривается вместе с изображениями.

## Запуск в Colab

Блокнот `colab/LR06_23.ipynb` загружается в Google Colab как отдельная работа. Среда выполнения — Python с GPU T4. Ячейки выполняются по порядку.

В разделе 3 открываются четыре окна загрузки. В них последовательно выбираются файлы из этой лабораторной:

1. `lab05_lib.py`;
2. `lab06_lib.py`;
3. `tools/run_lab06.py`;
4. `reports/hypothesis.md`.

Файлы размещаются в `/content/LR06`. Следующая ячейка показывает гипотезу до запуска модели. Раздел 5 выполняет эксперимент, раздел 6 выводит таблицы и изображения, раздел 7 скачивает ZIP с результатами.

Папка `v23_…` из архива сохраняется в `artifacts/`. Выполненный блокнот скачивается через меню «Файл → Скачать → Скачать IPYNB» и сохраняется в `colab/` с прежним именем. Вывод ячеек остаётся в блокноте.

`RESULT: PASS` означает, что измерения и технические проверки завершены. Подтверждение гипотезы определяется по результатам. Каждый запуск создаёт отдельную папку, включая незавершённые запуски с журналом ошибки.

## Отчёт

В отчёт Word включены цель и гипотеза, бриф, условия запуска, таблица по пяти seed, сравнительный лист, разбор проверки guidance=1 и вывод по каждому показателю. Визуальный анализ учитывает глубину зелёных слоёв, мягкость освещения и артефакты. Отдельно сопоставляются критерий 2s и практические допуски; рассматриваются ограничения CLIP, разброс seed и изменчивость времени на Colab.

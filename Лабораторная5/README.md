Сохранённые изображения, метрики, контрольные суммы и вывод блокнота прошли локальную проверку. Её можно повторить из папки лабораторной командой `python3 tools/verify_results.py`; требуется Python 3.10+ и Pillow.

## Эксперимент

Бриф описывает стилизованный полог леса сверху, зелёные слои и мягкий утренний свет. Запрос взят из `BRIEFS[3]` библиотеки преподавателя. Вариант задаёт seed 1023.

| Параметр | Значение |
|---|---|
| Модель | `stabilityai/sd-turbo` |
| Ревизия | `b261bac6fd2cf515557d5d0707481eafa0485ec2` |
| Размер | 512×512 |
| Шаги / guidance_scale | 1 / 0.0 |
| Вычисления / генератор | float16 на GPU / CPU |
| Условие A | Исходное изображение в PNG |
| Условие B | То же изображение после JPEG, quality=90 |
| Практический допуск | PSNR≥40 дБ |

Для пары A/B выполняется одна генерация. После кодирования и декодирования сравниваются пиксели, максимальная разность, MSE и PSNR. Размеры файлов и их SHA-256 записываются отдельно. По изображениям оценивается сохранение глубины зелёных слоёв.

Если пиксели совпадают, результат классифицируется как `identical`. При разных пикселях и PSNR≥40 дБ используется `close`, при меньшем PSNR — `different`. Эта классификация относится к численному отличию. Видимость JPEG-артефактов и пригодность картинки для публикации оцениваются отдельно.

Контрольные запуски проверяют повторяемость со свежим генератором, ошибку общего генератора и её исправление. Дополнительно исходное изображение сохраняется в PNG с уровнем сжатия 0 для проверки различия между хешем файла и равенством пикселей.

## Блокнот

`colab/LR05_23.ipynb` открывается через загрузку файла в Google Colab. Среда выполнения — Python с GPU T4. В разделе 3 последовательно загружаются три файла: `src/lab05_lib.py`, `tools/run_lab05.py` и `reports/hypothesis.md`. Для каждого файла открывается отдельное окно выбора. Ячейка размещает их в подпапках `/content/LR05` и выводит контрольные суммы.

Ячейки выполняются последовательно. Сначала фиксируется исходная среда, затем устанавливаются зависимости, создаются файлы эксперимента и запускается модель. Установка происходит до импорта библиотек модели. Фактические версии сохраняются в манифесте и `requirements-freeze.txt`; версии из примера преподавателя не подставляются вместо наблюдаемых.

Последняя ячейка формирует ZIP результатов и начинает скачивание. Выполненный блокнот с выводом ячеек сохраняется отдельно через «Файл → Скачать → Скачать IPYNB». Локальная папка для него — `colab/`, для распакованного запуска — `artifacts/v23_…/`.

Каждый запуск получает отдельную папку. `RESULT: PASS` означает завершение скрипта; результаты сравнения находятся в таблице. Веса модели в архив не включаются.

## Файлы запуска

| Файл | Содержание |
|---|---|
| `result.png`, `manifest.json` | Базовый результат и условия генерации |
| `A/result.png`, `A/manifest.json` | Исходный PNG, условие A |
| `B/result.jpg` | JPEG качества 90 для сравнения размера файла и просмотра |
| `B/result.png`, `B/manifest.json` | Декодированные JPEG-пиксели в PNG; манифест содержит хеши обоих файлов B |
| `comparisons.csv`, `comparisons.json` | Основная пара и контрольные сравнения |
| `file_comparison.json` | Размеры и хеши исходного PNG и JPEG |
| `controls/` | Повторные генерации и контроль PNG-кодирования |
| `generator_states.json` | Хеши состояния общего генератора до и после вызовов |
| `library_summary.json` | Результат `variant_summary(pipe, 23)` |
| `passport.json`, `environment.json` | Параметры, фактическая среда и результаты |
| `requirements-freeze.txt` | Версии пакетов сеанса |
| `sources/`, `hypothesis.md` | Копии кода и предварительной записи |
| `run.log` | Вывод и сообщения об ошибках |

`B/result.png` сохраняет уже изменённые JPEG-пиксели. Его размер не используется для вывода об экономии места JPEG: для этого сравниваются `A/result.png` и `B/result.jpg`.

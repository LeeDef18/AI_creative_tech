# Лабораторная 8 — вариант 23

Генерация и интерполяция в латентном пространстве VAE на наборе «цветной диск». Сравниваются линейный путь A и сферический путь B при одной обученной модели для каждого seed.

[Задание](ЛР08_Генерация_и_интерполяция_в_латентном_пространстве_МУ.pdf) · [Гипотеза](reports/hypothesis.md) · [Скрипт](tools/run_lab08.py) · [Команды Engee](engee/commands.jl) · [Контрольные вопросы](reports/control_questions.md)

Эксперимент выполнен 06.11.2026 в Engee на CPU. [Отчёт Word](reports/Король-Алексей-Юрьевич_ЛР1-8_вариант-23.docx) содержит измерения, диагностику, сравнительные листы и ответы на контрольные вопросы.

## Результаты

[Артефакты](artifacts/v23_20261106_151131_092752/) · [Итоговая таблица](artifacts/v23_20261106_151131_092752/summary.csv) · [Сравнительный лист](artifacts/v23_20261106_151131_092752/comparison.png) · [Журнал запуска](artifacts/v23_20261106_151131_092752/run.log) · [Проверка](reports/validation.log)

PSNR интерполяции составил 19,8348 дБ для линейного пути и 19,5260 дБ для сферического. Разность −0,3088 дБ укладывается в допуск ±1 дБ; критерий 2s не выполнен. При удвоении допуска оценка остаётся нейтральной. Реконструкция, сэмплы и R² совпали для каждого seed.

При малом угле между выбранными кодами пути почти одинаковы. Для пары с большим углом сферический путь лучше сохраняет оттенок и даёт более высокий PSNR, но это преимущество отдельной пары не переносится на всю серию. Оба пути неточно воспроизводят исходную палитру. Подробности сохранены в [наблюдениях](reports/observations.md).

Контрольные суммы и таблицы проверены. Для seed 101 PSNR интерполяции независимо пересчитан по 1200 сохранённым предсказаниям. Команда проверки из папки лабораторной — `python3 tools/verify_results.py`; требуется NumPy. Повторное обучение не выполняется.

Вывод консоли сохранён в текстовом журнале. Отдельного снимка интерфейса Engee в комплекте нет; методические указания предусматривают такой снимок.

## Условия

| Параметр | Значение |
|---|---|
| Данные | disc_color, 4096 train и 1024 test, seed 7 |
| Изображения | 3×32×32, float32, RGB в диапазоне 0–1 |
| Модель | ConvVAE, d=8, β=1 |
| Обучение | 30 эпох, Adam, lr=0.002, batch=128 |
| Разогрев KL | 10 эпох |
| Seed обучения | 101–105 |
| Интерполяция | A — lin, B — slerp; 200 пар с seed 11 |
| Точки оценки | t=0.25, 0.5, 0.75 |
| Сэмплы | 256 из N(0,I), seed=1000+seed обучения |
| Допуски | ±1 дБ для PSNR, ±0.05 для R² |

Основной отклик — PSNR интерполяции относительно сцен, построенных по промежуточным факторам. Реконструкция, сэмплы и R² служат контролем: смена пути их не затрагивает. Средние и разброс вычисляются по пяти seed; критерий 2s рассматривается отдельно от практического допуска.

Для цветного диска отдельно проверяется плавность оттенка. В библиотеке эталон использует арифметическую интерполяцию параметра цвета. Из-за периодичности оттенка такой переход не всегда кратчайший по цветовому кругу. Это ограничение сохраняется в анализе метрик.

## Воспроизведение

Для запуска требуется Python 3.11 с PyTorch, NumPy и Pillow. Базовая конфигурация для CPU — PyTorch 2.4.1, NumPy 1.26.4 и Pillow 11.3.0. Зависимости устанавливаются в отдельное виртуальное окружение лабораторной. Фактические версии записываются в `environment.json`.

Из корня папки лабораторной эксперимент запускается командой:

```bash
python tools/run_lab08.py --engee-version VERSION --julia-version VERSION
```

Аргументы содержат версии среды, в которой выполняется эксперимент. Для Engee команды подготовки окружения приведены в [setup.jl](engee/setup.jl), проверки и запуска — в [commands.jl](engee/commands.jl). При размещении на сервере в одной папке используются файлы `lab07_lib.py`, `lab08_lib.py`, `lab08_demo.py`, `run_lab08.py` и `hypothesis.md`. Скрипт поддерживает как структуру репозитория, так и такое размещение.

Сначала выполняется демонстрационный пример, затем вариант 23 и диагностика AE. Всего предусмотрено 27 обучений; повторные оценки используют кэш моделей. На CPU выполнение может занять десятки минут.

Результаты и журнал сохраняются в `artifacts/v23_…/`; по завершении создаётся ZIP. По разделу 8 методических указаний комплект для сдачи должен включать отчёт Word, скрипты, паспорт, сравнительный лист и снимок итогового вывода консоли.

Вариант 23 сохраняет реализацию slerp из задания. При разных нормах конечных векторов её путь не лежит точно на сфере постоянного радиуса. Для почти коллинеарных векторов используется линейная ветвь. Латентный вектор оценивается через μ; в обучении VAE применяется репараметризация.

# Гипотеза и допуски — вариант 23

Дата подготовки — 06.11.2026. Запись составлена до собственного запуска. Изучены методические указания и демонстрационные материалы преподавателя; приведённые в них закономерности использованы как ориентир.

Набор disc_color описывает цветной диск на градиентном фоне. Четыре фактора сцены — положение по x и y, радиус и оттенок. В режиме A используется линейная интерполяция, в B — сферическая (slerp из библиотеки преподавателя). Для каждой пары A/B используется одна и та же обученная модель. Реконструкция, сэмплы и R² служат контролем и должны совпасть.

Фиксированы ConvVAE, d=8, β=1, 30 эпох, разогрев KL за 10 эпох, Adam с lr=0.002 и batch=128. Данные 32×32 создаются с seed 7: 4096 train и 1024 test. Серия seed обучения — 101–105. Для интерполяции выбираются 200 пар тестовых сцен с seed 11; сравнение проводится при t=0.25, 0.5 и 0.75. Эталон строится по арифметической интерполяции факторов исходных сцен, как в задании. Сэмплы — 256 векторов из N(0,I), seed=1000+seed обучения.

Ожидается небольшое различие PSNR интерполяции, в пределах ±1 дБ, без устойчивого преимущества сферического пути. Для пар с большим углом между кодами геометрические пути могут заметно разойтись; влияние на изображение также зависит от норм векторов и декодировщика. Предполагается плавное изменение цвета в большинстве показанных кадров, однако возможны размытие и сдвиги оттенка. Эти предположения проверяются по изображениям, а не выводятся из одного среднего PSNR.

| Метрика | Практический допуск | Назначение |
|---|---|---|
| PSNR интерполяции | ±1.0 дБ | Основной отклик; рост более 1 дБ — улучшение, падение более 1 дБ — ухудшение |
| PSNR реконструкции | ±1.0 дБ | Контроль совпадения A/B; ожидается Δ=0 |
| PSNR сэмплов | ±1.0 дБ | Контроль совпадения A/B; ожидается Δ=0 |
| R² факторов | ±0.05 | Контроль совпадения A/B; ожидается Δ=0 |

Изменение на границе допуска считается нейтральным. Пороги приняты по образцу задания. После основной оценки проверяется чувствительность к удвоению допусков. Для каждого показателя рассчитываются среднее A, выборочное стандартное отклонение s по пяти seed A, среднее B, Δ=B−A, |Δ|/s и критерий |Δ|>2s. Этот учебный критерий сопоставляется с практическим допуском и не заменяет проверку гипотез с p-value. Контрольные показатели не используются как аргумент в пользу одного пути.

Дополнительно сохраняются PSNR каждого пути по всем 200 парам и трём точкам, нормы и угол латентных векторов. Для seed 101 показываются заранее выбранные тестовые сцены 0 и 2, а также пары с минимальным и максимальным углом среди 200 пар. Последние используются для иллюстрации геометрии, а не как отдельная подтверждающая выборка.

Диагностика включает разброс μ и KL по осям. Ось VAE считается активной при среднем KL>0.05 нат. Для обычного автокодировщика β=0 проверяются распределение μ и сэмплы из N(0,I); число активных осей по KL для него не интерпретируется, поскольку соответствующая ветвь не обучается. Отдельно выполняется демонстрационный вариант 1, включая сравнение обучения с разогревом KL и без него.

Оттенок периодичен. Арифметическая интерполяция параметра оттенка между 0.98 и 0.02 проходит через 0.5, хотя крайние цвета близки. Поэтому эталон задания не всегда соответствует кратчайшему цветовому переходу. R² по числовому оттенку тоже чувствителен к этому разрыву. Сравнение путей сохраняет исходное определение метрик; ограничение учитывается при выводах.

PSNR ближайшего соседа показывает близость сэмплов к тестовым сценам, но не оценивает разнообразие. Высокое значение само по себе не исключает схлопывание. Результаты ограничены синтетическим набором, одной архитектурой и пятью seed.

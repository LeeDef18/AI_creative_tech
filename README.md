## Структура репозитория

Каждая лабораторная находится в отдельной папке `ЛабораторнаяN/`. Её README содержит ссылки на задание, результаты и команды для повторения работы.

- `src/` — исходный код лабораторной.
- `artifacts/` — результаты запусков, паспорта и другие материалы работы.
- `reports/` — итоговый отчёт Word, журнал и записи экспериментов.
- `demo_journal/` — примеры преподавателя.
- `tools/` — вспомогательные скрипты, если они нужны для работы.

Дополнительные папки описаны в README соответствующей лабораторной.

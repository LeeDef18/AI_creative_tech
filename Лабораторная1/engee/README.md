# Часть Б — подготовка рабочей области Engee

Статус: действия выполнены; наблюдения сохранены в observations.md. Ниже сохранён порядок выполнения.

1. Войти в личный кабинет Engee. Записать дату/время (Europe/Moscow), версию кабинета и версию среды в заголовке вкладки.
2. В панели «Файлы» создать `/user/AI_creative_tech/LR01`. Записать фактическое название пункта создания папки.
3. Создать в редакторе скрипт `LR01_environment.ngscript`, сохранить в этой папке. В одну ячейку вставить код из [LR01_environment.jl](LR01_environment.jl). Файл .jl содержит текст для вставки; формат .ngscript создаёт сама Engee.
4. Выполнить ячейку. Скопировать весь вывод VERSION и versioninfo() без исправлений в [наблюдения](observations.md). Если VERSION не выводится автоматически в составной ячейке, отдельно выполнить VERSION в командной строке и записать это действие. При ошибке сохранить точный текст сообщения; не подменять результат ожидаемым.
5. Открыть «Переменные» → «Рабочая область», найти seed и записать имя, значение и класс.
6. Выполнить «Очистить все переменные», записать, что стало с таблицей.
7. Затем выполнить «Перезапуск ядра» и снова записать состояние таблицы. Не запускать ячейку между этими действиями, чтобы не менять порядок проверки.
8. Загрузить [паспорт](../artifacts/v23/passport.md) в LR01. Сохранить скрипт и скачать его в эту папку репозитория. Дополнить паспорт и отчёт фактическими наблюдениями; загрузить дополненный паспорт в Engee повторно.

Запишите фактические названия кнопок, если они отличаются от методички. В скриншотах не показывайте адресную строку с логином. Учётные данные в репозиторий не помещаются.

Для оформления результатов нужны: версии, вывод команд, список созданных файлов, наблюдения до очистки/после очистки/после перезапуска и сохранённый скрипт. При наличии этих данных можно завершить раздел отчёта и паспорт.

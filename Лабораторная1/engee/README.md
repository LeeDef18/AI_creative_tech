## Порядок выполнения и результаты

В рабочей папке созданы скрипт `LR01_environment.ngscript` и копия паспорта `passport.md`. В ячейке выполнены команды определения версии Julia и сведений о среде, затем присваивание `seed = 101`.

| Этап | Результат |
|---|---|
| Выполнение ячейки | В рабочей области появилась переменная `seed`, значение `101`, тип `Int64` |
| Очистка переменных | Переменная `seed` исчезла |
| Перезапуск ядра | Рабочая область осталась пустой |

Между очисткой переменных и перезапуском ядра ячейка повторно не выполнялась. После проверки скрипт сохранён и скачан в репозиторий.

## Повторение проверки

Код из `LR01_environment.jl` выполняется в ячейке скрипта Engee. Последовательность проверки: выполнение ячейки, просмотр `seed`, очистка переменных, перезапуск ядра. Повторное выполнение ячейки после перезапуска вновь создаёт `seed`.

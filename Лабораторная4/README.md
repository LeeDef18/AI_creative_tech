PSNR карты границ вырос с 21,1761 до 23,2520 дБ: прирост 2,0759 дБ превышает основной порог +1 дБ. Операция полезна для выбранной сцены. Энергия границ и контраст снизились; визуально подавление шума сопровождается размытием реальных границ. Для сцены без шахматной добавки прирост составил 3,7638 дБ.

## Постановка эксперимента

Сцена 128×128: фон 0,10–0,40, яркость диска 0,75, шахматная добавка 0,10, размер клетки 8, гауссов шум 0,05. Серия seed: 101–105.

| Элемент сравнения | Определение |
|---|---|
| Базовая карта | Модуль градиента Собеля зашумлённой сцены |
| Результат | Сглаживание Гауссом с σ=1, затем модуль градиента Собеля |
| Эталон | Модуль градиента Собеля чистой сцены без предварительного сглаживания |
| Нормировка | Общий максимум градиента чистой сцены; ограничение значений единицей |
| Метрики | PSNR относительно эталонной карты, энергия границ и контраст полученной карты |

Энергия границ вычисляется функцией `edge_energy` от карты, возвращённой `pair4`, как в сводке преподавателя. Это не среднее значение самой карты Собеля. Контраст — выборочное стандартное отклонение её значений.

Практическая оценка определяется по разности средних PSNR: от +1 дБ — полезна, до −1 дБ включительно — вредна, между порогами — нейтральна. Для каждой метрики отдельно проверяется учебный критерий `abs(Δ)>2s`. Гипотеза и обоснование допуска записаны до запуска.

Дополнительные проверки: сцена без шахматной добавки при том же шуме (вариант 11), чувствительность к допускам ±0,5 и ±2 дБ, сопоставление демо-варианта 1 с журналом преподавателя. PSNR самой зашумлённой сцены сравнивается с теоретической оценкой около 26,02 дБ отдельно от PSNR карт границ.

## Запуск в Engee

Рабочая папка — `/user/AI_creative_tech/LR04`. В ней размещаются четыре файла:

| Файл репозитория | Имя в Engee |
|---|---|
| `src/lab03_lib.jl` | `lab03_lib.jl` |
| `src/lab04_lib.jl` | `lab04_lib.jl` |
| `engee/LR04_23.jl` | `LR04_23.jl` |

Команды для Engee 26.9.2-H4:

```julia
cd("/user/AI_creative_tech/LR04")
include("LR04_23.jl")
result_dir = LR04.run_experiment(engee_version="26.9.2-H4")
```

Параметр `engee_version` должен соответствовать фактической версии среды. Скрипт создаёт отдельную папку `artifacts/v23_…`, сохраняет гипотезу и копии исходных файлов до расчётов. Ошибка во время эксперимента записывается в `run.log`. Успешное выполнение заканчивается сообщением `RESULT: PASS`; совпадение демо с опубликованными числами фиксируется отдельным полем `demo_match`.

Библиотека ЛР 4 проверяет наличие `psnr_db` в `Main`. Скрипт предварительно подключает библиотеку ЛР 3 в собственном модуле, чтобы расчёт не зависел от функций предыдущей сессии. Исходные библиотеки не редактировались.

Метрики рассчитываются по массивам Float64 до экспорта. PNG с 8 битами на пиксель используются для визуального сравнения. Основной эталон варианта 23 — `edges_reference.png`; `clean.png` показывает чистую сцену до Собеля.

Режим обработки края — продолжение крайних значений (`replicate`). В скрипте результат вызовов библиотеки сравнивается с явным указанием этого режима. Описание параметра: [документация ImageFiltering](https://juliaimages.org/ImageFiltering.jl/latest/function_reference.html).

```bash
python3 tools/verify_results.py
```

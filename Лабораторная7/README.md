# Лабораторная 7 — вариант 23

Построение шумоподавляющего автокодировщика для набора «цветной диск». Режим A обучается на чистых изображениях, режим B — на изображениях с шумом σ=0.2. Оба режима оцениваются на одинаковых зашумлённых входах относительно чистого оригинала.

Эксперимент выполнен 15.10.2026 в Google Colab на Tesla T4. [Отчёт Word](reports/Король-Алексей-Юрьевич_ЛР1-7_вариант-23.docx) содержит измерения, сравнительный лист, диагностику латентного вектора и ответы на контрольные вопросы. В блокноте сохранён вывод выполненных ячеек.

## Результаты

[Папка запуска](artifacts/v23_20261015_170113_333088/) · [Таблица](artifacts/v23_20261015_170113_333088/summary.csv) · [Сравнительный лист](artifacts/v23_20261015_170113_333088/comparison.png) · [Наблюдения](reports/observations.md) · [Проверка](reports/validation.log)

Шумоподавляющее обучение повысило средний тестовый PSNR с 17,2087 до 20,6153 дБ. Эталон «средняя картинка» дал 18,1203 дБ: режим A оказался ниже него на 0,9116 дБ, режим B — выше на 2,4950 дБ. Разрыв train−test режима B составил 0,0531 дБ. Число параметров осталось равным 101 035, время обучения выросло на 96,58%.

Прирост PSNR превышает допуск 1 дБ. Критерий 2s выполнен с небольшим запасом: |Δ|/s=2,011. При удвоении практических допусков классификации сохраняются. На сравнительном листе B лучше выделяет диск и очищает фон, однако оттенок заметно смещается. Точное восстановление цвета не достигнуто.

Проверены контрольные суммы, выполненный блокнот, таблицы и значения PSNR каждого изображения. По сохранённым float32-массивам независимо пересчитаны эталоны и реконструкции seed 101 основной и демонстрационной серий. Проверка запускается из папки лабораторной командой `python3 tools/verify_results.py`; достаточно Python 3.10+. Повторное обучение при проверке не выполняется.

## Данные и модель

Сцены создаются кодом без загрузки внешних изображений. У цветного диска четыре фактора: координаты центра, радиус и оттенок. Данные фиксированы seed 7, а seed 101–105 используются для пяти запусков обучения каждого режима.

| Параметр | Значение |
|---|---|
| Размер изображения | 3×32×32, RGB в диапазоне 0–1 |
| Выборки | 4096 обучающих и 1024 тестовых сцены |
| Модель | ConvAE, свёрточный автокодировщик |
| Латентный вектор | d=8 |
| Обучение | MSE, Adam, lr=0.002, batch=128 |
| Продолжительность | 20 эпох, 640 обновлений весов |
| Режим A | Чистый обучающий вход |
| Режим B | Шум σ=0.2 на обучающем входе |
| Цель обучения | Чистое изображение в обоих режимах |
| Оценка | Общий вход с шумом σ=0.2, seed шума 1234 |

Кодировщик уменьшает изображение до вектора из восьми чисел. Декодировщик восстанавливает из него изображение. Число параметров одинаково в A и B; в основной серии меняется только шум на обучающем входе.

## Измерения

PSNR сначала вычисляется для каждого тестового изображения, затем усредняется. Разрыв train−test определяется по первым 1024 обучающим сценам и всей тестовой выборке. В основной таблице приводятся средние A/B, выборочное стандартное отклонение A, разность средних и критерий 2s.

Практические допуски записаны до собственного запуска: ±1 дБ для PSNR, ±0.1 дБ для разрыва, ±20% для времени. Число параметров рассматривается как характеристика архитектуры. При s=0 и Δ=0 отношение 0/0 не определено; в итоговой таблице для него сохраняется пустое значение. Необработанный вывод библиотеки хранится отдельно.

Для оценки качества используется эталон «средняя картинка», рассчитанный по обучающей выборке. Дополнительно измеряется PSNR зашумлённого входа без обработки. На изображениях проверяются положение диска, радиус, оттенок и границы.

Диагностика d=1,2,3,4,8 выполняется на seed 101–103 при чистом обучении и чистой оценке, как в демонстрационном коде. Она отделена от основной серии шумоподавления. Сначала выполняются демонстрационный вариант 1 и его диагностика, затем вариант 23. Всего предусмотрены 52 обучения, включая прогрев.

## Запуск

Блокнот `colab/LR07_23.ipynb` загружается в Google Colab как отдельная работа. Среда выполнения — Python с GPU T4. Используются установленные PyTorch, NumPy и Pillow; их версии записываются при запуске.

Ячейки выполняются по порядку. Раздел 3 последовательно запрашивает три файла:

1. `ЛР07_Построение_автокодировщика/src/lab07_lib.py`;
2. `tools/run_lab07.py`;
3. `reports/hypothesis.md`.

В Colab они размещаются в `/content/LR07`. Следующая ячейка показывает гипотезу. Раздел 5 запускает обучение, раздел 6 выводит таблицы и сравнительные листы, раздел 7 скачивает архив. Папка `v23_…` из архива сохраняется в `artifacts/`. Выполненный блокнот скачивается в формате IPYNB с выводом ячеек и заменяет файл в `colab/`.

Каждый запуск создаёт отдельную папку. Журнал сохраняется и при ошибке. `RESULT: PASS` означает завершение расчётов и технических проверок; проверка гипотезы опирается на полученные значения и изображения.

## Исходные материалы

Папка `ЛР07_Построение_автокодировщика/` содержит задание, библиотеку, демонстрационный код и журнал преподавателя. Файлы `lab07_lib.py` и `lab07_lib(1).py` совпадают по SHA-256; для запуска используется первый. Материалы сохранены без изменений.

Сводка `results_30_variants.json` относится к запускам преподавателя. Она не заменяет собственные измерения. Побитовое совпадение после повторного обучения на GPU не гарантируется; сопоставляются значения и разброс по seed.

В библиотеке один генератор используется для перемешивания обучающей выборки и добавления шума. Поэтому в режиме B расход случайных чисел меняется и порядок пакетов в следующих эпохах может отличаться. Это особенность исходной методики, которую следует учитывать при объяснении эффекта. Пять seed снижают зависимость вывода от отдельного обучения.

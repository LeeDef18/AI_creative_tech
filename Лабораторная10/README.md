# Лабораторная 10 — вариант 23

Сравнение LCM Dreamshaper v7 и aMUSEd-256 для визуала к лекциям по экологии. Обе модели получают один бриф о лесном пологе сверху. Эксперимент включает измерения на пяти seed и слепую оценку пяти пар.

[Задание](ЛР10_Сравнительное_исследование_моделей_text-to-image_МУ.pdf) · [Гипотеза](reports/hypothesis.md) · [Скрипт запуска](tools/run_lab10.py) · [Источники моделей](reports/model_sources.md)

Эксперимент выполнен 18.11.2026. [Отчёт Word](reports/Король-Алексей-Юрьевич_ЛР1-10_вариант-23.docx) содержит измерения, сравнение изображений и анализ.

LCM дала clip_brief 27,565 против 23,634 у aMUSEd. У aMUSEd выше edge и contrast, но кроны леса узнаются хуже. Среднее время — 33,24 и 36,25 с соответственно. Все разности превысили 2s; различие времени меньше практического порога 1,5 раза.

[Личная оценка пяти пар](reports/blind_result.json) дала LCM 5 побед из 5. Пять пар не устанавливают общий рейтинг моделей.

Бриф:

> visual for an ecology lecture series, stylized forest canopy seen from above, layered green shapes, soft morning light, no text, no people

Общие условия — CPU, float32, четыре потока, seed 101–105. Ревизии закреплены в `src/lab10_lib.py`. Модели загружаются по очереди. После прогрева с seed 0 время измеряется только внутри вызова генерации. Метрики CLIP оцениваются отдельно; edge и contrast рассчитываются после приведения к 256×256.

Основная гипотеза сравнивает силу различий по edge, contrast и clip_brief через |Δ|/s. Практические допуски — 1 пункт для CLIP, 10% среднего A для edge/contrast и различие времени более чем в 1,5 раза. Подробная предварительная запись приведена в гипотезе.

## Запуск в Engee

В папке `/user/AI_creative_tech/LR10` размещаются четыре файла:

| В репозитории | В Engee |
|---|---|
| `src/lab10_lib.py` | `lab10_lib.py` |
| `tools/run_lab10.py` | `run_lab10.py` |
| `reports/hypothesis.md` | `hypothesis.md` |
| `engee/setup.jl` | `setup.jl` |

Подготовка использует готовое окружение ЛР 9, если оно доступно. При его отсутствии создаётся отдельное окружение в LR10.

```julia
cd("/user/AI_creative_tech/LR10")
include("setup.jl")
engee_version = "ВЕРСИЯ_ИЗ_ИНТЕРФЕЙСА"
run(`$PY -u run_lab10.py --engee-version $engee_version --julia-version $(string(VERSION))`)
```

Версия Engee задаётся по текущему интерфейсу. Первый запуск загружает веса двух моделей и CLIP. В методичке для генерации указано около 6–8 минут без длительной первой загрузки; фактическое время зависит от сеанса.

Скрипт сохраняет полный архив `v23_….zip` и отдельный `v23_…_blind.zip`. В консоли выводится прогресс без таблицы качества и результатов раскрытия ключа. Повторный запуск создаёт новую папку; результаты разных сеансов не смешиваются.

## Слепая оценка

Для оценки используется архив с окончанием `_blind.zip`. Он содержит пять листов `blind_101.png` … `blind_105.png`, текст брифа и пустую таблицу `choices.csv`. В каждой строке фиксируются `left` или `right` и причина выбора. Критерии — вид сверху на кроны, зелёные слои, глубина, мягкий утренний свет и отсутствие людей и текста.

До фиксации пяти решений ключ, подписанные изображения и сравнительный лист остаются закрытыми. Ключ находится только в полном архиве. После сохранения выбора подсчёт выполняется из папки лабораторной:

```bash
python3 tools/score_blind.py reports/blind_choices.csv artifacts/ПАПКА_ЗАПУСКА/blind_key.json --output reports/blind_result.json
```

Рабочая заполненная таблица сохраняется в reports/, исходный пустой шаблон в артефактах остаётся неизменным. Пять пар дают лишь наблюдение. Даже пять побед одной модели соответствуют двусторонней вероятности 0,0625 при равных шансах.

Метрики считаются по исходным изображениям до JPEG-сжатия. Слепые листы формируются функцией преподавателя по JPEG quality=90 с одинаковым размером показа 384×384. Разное исходное разрешение может оставаться заметным и ограничивает полноту маскировки модели.

# Ответы языковой модели

Здесь сохраняются полные ответы девяти независимых чатов без редактирования.

| Приём | Имена файлов |
|---|---|
| Zero-shot | `ctx4_zero_r1.txt`, `ctx4_zero_r2.txt`, `ctx4_zero_r3.txt` |
| Few-shot | `ctx4_few_r1.txt`, `ctx4_few_r2.txt`, `ctx4_few_r3.txt` |
| Пошаговый | `ctx4_step_r1.txt`, `ctx4_step_r2.txt`, `ctx4_step_r3.txt` |

Исходные запросы находятся в `../prompts/`, паспорт чатов — в `../reports/llm_passport.csv`. Пояснения модели перед JSON и ограждения блока кода сохраняются вместе с ответом.

## Два этапа и продолжение

При необходимости подготовка отделяется от расчёта:

```julia
run(`$PY -u run_lab13.py --stage prep --engee-version $engee_version --julia-version $(string(VERSION))`)
```

После `PREP: PASS` путь к созданной папке подставляется в следующую команду:

```julia
result_dir = "/user/AI_creative_tech/LR13/artifacts/v23_ПАПКА_ЗАПУСКА"
run(`$PY -u run_lab13.py --stage calc --run-dir $result_dir --engee-version $engee_version --julia-version $(string(VERSION))`)
```

Для продолжения прерванного общего запуска используется та же папка и `--stage all`. Исходники и гипотеза сверяются с копиями запуска. Готовый файл пулов пропускает повторное обучение; готовые признаки каждого пула и завершённые измерения пропускаются. Если прервано обучение до записи общего файла генераций, подготовка повторяет оба обучения — библиотека не возобновляет оптимизаторы. Повторные сеансы фиксируются в `sessions.json`.

## Расчёты и ограничения

Сравнение содержит FID, FID_inf, KID×1000 и время одного FID по готовым признакам. FID_inf экстраполируется по трём точкам N/4, N/2, N к 1/N=0. KID — несмещённая оценка MMD² с полиномиальным ядром; отрицательные оценки допустимы. Все вычисления расстояний выполняются в float64 по признакам, сохранённым в float32.

Практические допуски выбраны до запуска: 10% абсолютного среднего A для FID и FID_inf, 5 пунктов для KID×1000 и отношение времени >1,5. Превышение 2s проверяется отдельно. Предполагается, что сильный D повысит FID и ухудшит образцы; результат может не подтвердить это ожидание.

Для базовой модели строится график при N=125, 250, 500, 1000, 2000 с каждой стороны, по пяти подвыборкам. На графике показаны среднее и выборочное s. Точка N=1000 использует уже рассчитанный FID режима A с теми же seed. Изменение N исследуется как условие оценки, а не как улучшение модели.

Контроли включают FID двух независимых гауссовых выборок с d=2048 при N=500 и 2000. Дополнительно проверяются одинаковые признаки (FID≈0) и сдвиг среднего на (1,2) без изменения ковариации (FID≈5).

По реализации преподавателя base_3000 имеет пул 2048 генераций, strong_3000 — 1024. В главной таблице N=1000 в обоих режимах; разные конечные пулы влияют на возможный разброс подвыборок. Генерации квантованы в uint8 и перед извлечением делятся на 255, реальные сцены используются из float32. Эти условия входят в анализ.

На образцах рассматриваются форма диска, однородность заливки, диапазон оттенков, смешение цветов, повторы и фоновые артефакты. Inception связана с естественными фотографиями и ограниченно описывает синтетические сцены. Абсолютные значения не сопоставляются с FID из публикаций на других данных.

Общий `feat13_disc_color.npz` превышает лимит размера одного файла GitHub и дублирует десять отдельных `part13_disc_color_*.npy`. В Git сохраняются отдельные файлы; общий NPZ остаётся локально и исключён через `.gitignore`.

```bash
python3 tools/rebuild_features.py artifacts/v23_20261127_073005_242149
```

Скрипт проверяет SHA-256 по исходному `artifact_hashes.json`. Восстановление проверено: архив побайтово совпадает с результатом Engee. `verify_results.py` также восстанавливает его автоматически при отсутствии. Научные результаты и исходные контрольные суммы сохраняются.

# Проверка результатов ЛР 3

Проверены пять строк серии, средние и выборочные стандартные отклонения, Δ, отношения |Δ|/s, относительные изменения, решения по порогам, формула PSNR по MSE и средний PSNR. Значения согласованы с summary.csv и passport.toml.

Гистограммы содержат по 32 интервала и по 16384 отсчёта; их энтропия согласуется с метриками seed 101. Три изображения имеют размер 128×128. Контрольная сумма базового массива в серии совпадает с двумя значениями паспорта. Повторная генерация в Engee подтверждена журналом; локально массивы Float64 не пересоздавались.

Хеши скрипта и гипотезы совпадают с паспортом. Гипотеза запуска совпадает с предварительной записью.

Хеши файла библиотеки различаются:
- в паспорте Engee: `acfe83734ecc33366859afeac20ae17db1f7c0100e8e1a8da0bb1c9ca7f7bbcc`;
- в репозитории: `cd1622643e7cfe7cc01bb7d8067e4802a76f6a76e9a6833ba4c09c84bb9fa62a`.

## Постановка эксперимента

Сцена 128×128 с параметрами lo=0.15, hi=0.85, noise=0.08, checker=0. Яркость преобразуется по формуле y=sqrt(x). Метрики — средняя яркость, контраст и энтропия гистограммы из 32 интервалов; отличие от исходного массива измеряется PSNR. Серия включает seed 101–105.

До запуска заданы критерии: |Δ|>2s для учебной статистической оценки; относительное изменение метрики больше 5% и PSNR ниже 30 дБ для практической оценки. Полное обоснование находится в записи гипотезы.

## Повторение эксперимента

В Engee используется рабочая папка `/user/AI_creative_tech/LR03`. Для запуска в ней должны находиться три файла:

| Файл в репозитории | Имя в рабочей папке Engee |
|---|---|
| `src/lab03_lib.jl` | `lab03_lib.jl` |
| `engee/LR03_23.jl` | `LR03_23.jl` |
| `reports/hypothesis.md` | `hypothesis.md` |

Команды запуска для среды, использованной в работе:

```julia
cd("/user/AI_creative_tech/LR03")
include("LR03_23.jl")
result_dir = LR03.run_experiment(engee_version="26.9.2-H4")
```

Параметр `engee_version` записывается в паспорт и должен соответствовать версии среды при повторном запуске. Гипотеза и критерии сохраняются в папку результатов до генерации сцены.

Каждый запуск создаёт отдельную папку `artifacts/v23_…` с журналом, изображениями, таблицами и паспортом. Её путь возвращается в `result_dir`. В репозитории папки запусков находятся в `Лабораторная3/artifacts/`. Сообщение `RESULT: PASS` означает, что предусмотренные скриптом проверки завершились успешно.

## Результаты запуска

| Файл | Содержание |
|---|---|
| `run.log` | Среда, свойства сцены, сравнение яркости, SHA-256, значения по seed и сводка |
| `passport.toml` | Паспорт эксперимента с параметрами, версиями, критериями и результатами |
| `hypothesis.md` | Копия записи, сохранённая до генерации сцены |
| `scene_rgb.png` | Исходная цветная сцена для seed 101 |
| `before.png`, `after.png` | Яркость до и после гамма-коррекции для seed 101 |
| `histograms.png`, `histogram.csv` | Гистограммы на одинаковых осях и исходные частоты |
| `series.csv` | Метрики, MSE, PSNR и хеши по каждому из пяти seed |
| `summary.csv` | Средние метрики, s, Δ, &#124;Δ&#124;/s и оценки по двум критериям |
| `sensitivity.csv` | Изменение выводов при допусках 1%, 5% и 10% |

Метрики считаются по массивам Float64 до сохранения PNG. PNG имеют 8 бит на канал и используются как иллюстрации. Повторная генерация seed 101 проверяется по полному массиву и SHA-256. Два способа вычисления яркости сравниваются с допуском 1e-7. Сводка дополнительно сверяется с `variant_summary(23)` из библиотеки преподавателя.

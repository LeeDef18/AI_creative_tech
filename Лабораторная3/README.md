## Что исследуем

Сцена 128×128 с параметрами lo=0.15, hi=0.85, noise=0.08, checker=0. Яркость преобразуется по формуле y=sqrt(x). Метрики — средняя яркость, контраст и энтропия гистограммы из 32 интервалов; отличие от исходного массива измеряется PSNR. Серия включает seed 101–105.

До запуска заданы критерии: |Δ|>2s для учебной статистической оценки; относительное изменение метрики больше 5% и PSNR ниже 30 дБ для практической оценки. Полное обоснование находится в записи гипотезы.

## Запуск в Engee

1. Прочитай [гипотезу](reports/hypothesis.md) до запуска. Если хочешь выбрать другой основной допуск, его нужно согласованно изменить в записи и скрипте до получения результатов.
2. Создай папку `/user/AI_creative_tech/LR03`.
3. Загрузи в неё три файла из репозитория, сохранив их имена:
   - `src/lab03_lib.jl`;
   - `engee/LR03_23.jl`;
   - `reports/hypothesis.md`.
4. Проверь текущую версию Engee в интерфейсе. Не переноси автоматически версию из прошлой работы.
5. Выполни команды ниже. Вместо `ТЕКУЩАЯ_ВЕРСИЯ` укажи версию своей сессии:

```julia
cd("/user/AI_creative_tech/LR03")
include("LR03_23.jl")
result_dir = LR03.run_experiment(engee_version="ТЕКУЩАЯ_ВЕРСИЯ")
```

Первая загрузка пакетов может занять время. При ошибке сохрани её полный текст; не исправляй метрики вручную. Повторные запуски создают отдельные папки результатов.

6. После `RESULT: PASS` открой `before.png`, `after.png` и `histograms.png` в папке, путь к которой напечатан в конце. Запиши собственные наблюдения: стало ли изображение светлее, как выглядит шум и куда сместились основные столбцы гистограммы. `PASS` означает успешное выполнение проверок, а не подтверждение гипотезы.
7. Скачай созданную папку `artifacts/v23_…` целиком и помести её в локальную `Лабораторная3/artifacts/`, сохранив имя папки запуска. Для начала разбора достаточно прислать текст `run.log`; для отчёта нужны также изображения и таблицы.

## Результаты запуска

| Файл | Содержание |
|---|---|
| `run.log` | Среда, свойства сцены, сравнение яркости, SHA-256, значения по seed и сводка |
| `passport.toml` | Паспорт эксперимента с параметрами, версиями, критериями и результатами |
| `hypothesis.md` | Копия записи, сохранённая до генерации сцены |
| `scene_rgb.png` | Исходная цветная сцена для seed 101 |
| `before.png`, `after.png` | Яркость до и после гамма-коррекции для seed 101 |
| `histograms.png`, `histogram.csv` | Гистограммы на одинаковых осях и исходные частоты |
| `series.csv` | Метрики, MSE, PSNR и хеши по каждому из пяти seed |
| `summary.csv` | Средние метрики, s, Δ, |Δ|/s и оценки по двум критериям |
| `sensitivity.csv` | Изменение выводов при допусках 1%, 5% и 10% |

Метрики считаются по массивам Float64 до сохранения PNG. PNG имеют 8 бит на канал и используются как иллюстрации. Повторная генерация seed 101 проверяется по полному массиву и SHA-256. Два способа вычисления яркости сравниваются с допуском 1e-7. Сводка дополнительно сверяется с `variant_summary(23)` из библиотеки преподавателя.

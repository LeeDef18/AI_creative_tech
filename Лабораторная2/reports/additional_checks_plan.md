# План дополнительных проверок

После базового аудита: (1) проверить рабочий поднабор из семи записей; (2) на исходном наборе изменить только redistribution на true и проверить появление R7 для item01 и item09; (3) проверить намеренно испорченный реестр и затем исправленный. Это диагностические проверки; исходная политика варианта не меняется.

Ожидания: рабочий поднабор — 0 ошибок и 0 предупреждений; при публикации исходного набора — 2 ошибки и 3 предупреждения (два новых R7 и прежний R10). Испорченный реестр — FAIL из-за неверной категории, оценки вне шкалы, пустого owner, трёх рисков и трёх категорий. Финальный реестр — PASS и наличие обеих обязательных групп.
